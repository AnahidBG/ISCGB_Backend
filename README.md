  # ISCGB

Sistema de gestión para el Instituto Superior Cura Gabriel Brochero (ISCGB).

  ## Descripción del proyecto

El proyecto consiste en el desarrollo de un sistema web para la gestión administrativa del Instituto Superior Cura Gabriel Brochero (ISCGB).
El sistema permite centralizar diferentes procesos y brindar funcionalidades específicas según el rol del usuario, que son:
- Autogestión de Alumnos
- Autogestión de Docentes
- Autogestión de Secretaría
- Autogestión de Dirección

    ## Cómo instalar y ejecutar
1. Clonar el repositorio.
2. Abrir el proyecto en el entorno de desarrollo correspondiente.
3. Configurar la conexión con la base de datos.
4. Ejecutar las migraciones o scripts de base de datos.
5. Ejecutar la aplicación.

   ## Cómo contribuir
1. Clonar el repositorio.
2. Crear una nueva rama para los cambios.
3. Realizar las modificaciones correspondientes.
4. Realizar un commit con los cambios.
5. Subir la rama al repositorio.
6. Crear un Pull Request.

    ## Ejemplos de uso

### Autogestión de Alumnos
Los alumnos pueden acceder a las funcionalidades disponibles para su rol y gestionar su información.

### Autogestión de Docentes
Los docentes pueden acceder a las funcionalidades correspondientes a su perfil y gestionar la documentación relacionada.

### Autogestión de Secretaría
Secretaría puede gestionar información administrativa y académica.

### Autogestión de Dirección
Dirección puede acceder a información y funcionalidades de gestión institucional.
